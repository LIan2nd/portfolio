# Proyek Frontend: L-Movie (Movie & Cinema Discovery)

- **Live URL:** https://lmovie.liand.web.id
- **Konteks:** Proyek Ujian Tengah Semester (UTS) Mata Kuliah Pemrograman Frontend di STT Terpadu Nurul Fikri
- **Tech Stack:** HTML5, CSS3, JavaScript / React, Fetch API, TMDB / Movie Database API
- **Kategori:** Frontend Web Application / API Data Fetching

---

## 🎬 Ringkasan Proyek
**L-Movie** adalah platform web eksplorasi dan pencarian film yang dibangun oleh Alfian Nur Usyaid sebagai proyek UTS mata kuliah Pemrograman Frontend. Fokus utama proyek ini adalah menguasai teknik integrasi data asinkron (*asynchronous API fetching*) dari backend / third-party API film (seperti TMDB/IMDB) ke sisi antarmuka pengguna (*client-side*).

---

## ✨ Fitur & Konsep Utama
1. **API Data Fetching:** Mengambil dan mengolah data katalog film (poster, rating, sinopsis, tanggal rilis, dan genre) secara asinkron menggunakan REST API.
2. **Dynamic UI Rendering:** Merender daftar kartu film secara dinamis berdasarkan data JSON yang diterima dari API.
3. **Pencarian & Filter Film:** Memudahkan pengguna mencari judul film favorit dan melihat detail film secara instan.
4. **Responsive Layout:** Tampilan antarmuka yang adaptif dan nyaman diakses baik di perangkat mobile maupun desktop.
